## 1. 系统定位与设计哲学

传统媒体服务器（如 Plex、Emby、Jellyfin）往往存在架构臃肿、内存占用高（数以百兆计）、外网延迟大或转码配置复杂的问题。**NovaStream** 针对个人与家庭高端影音发烧友设计：

1. **极致轻量**：基于 Rust / Tauri 跨平台原生架构理念，前端采用高性能 React 与 Tailwind CSS，常驻内存低至约 **45MB**，冷启动小于 **350ms**。
2. **零死角硬解**：充分利用桌面 GPU 算力（NVIDIA NVENC、Intel QuickSync、Apple VideoToolbox、Linux VA-API），支持 4K HDR 实时转码与电影级色调映射。
3. **局域网亚秒级同步**：无需复杂的云端信令服务器，基于局域网广播通道（BroadcastChannel / UDP 组播模拟）实现多房间、多终端毫秒级播放同步。
4. **反 AI 模板化（Zero-Pill）设计**：摈弃泛滥的圆角药丸框与低质渐变，采用高端暗色影院视效、点号间距文字排版与高对比度易读性标准。

## 2. 核心架构与功能特性

### 2.1 智能元数据刮削工坊与多维媒体资产管理 (Metadata & Media Assets)
- **多源聚合识别**：集成 TMDB、豆瓣电影、Bangumi（番组计划）与 TVDb，支持海报壁纸、演职员表、评分数据全量抓取。
- **封面图库与海报切换 (Cover Art Gallery)**：
  - 支持在详情弹窗或刮削工坊中一键浏览 TMDB / 豆瓣 / Fanart.tv 高分辨率备选海报并即时切换。
  - 支持输入自定义网络图片 URL，或通过文件选择器上传本地电脑图片文件直接替换封面。
- **智能字幕抓取与本地外挂字幕管理 (Subtitles Management)**：
  - 集成在线字幕抓取模拟（射手网 Shooter / SubHD / OpenSubtitles），自动匹配中英双语特效 ASS、简中 SRT、英语 SDH 字幕，并提供 1 键下载绑定。
  - 支持选择本地电脑中的 `.srt`、`.ass`、`.vtt` 外挂字幕文件直接导入，即时注入播放器字幕轨道。
- **智能文件名正则解析器 (Regex Tokenizer)**：
  - 自动识别并拆解包含命名规格的文件（标题、年代、4K UHD、HEVC、Atmos、发布组）。
- **Kodi / Jellyfin / Emby XML NFO 导出**：自动生成标准 `.nfo` XML 文件，兼容第三方播放器与离线归档。

### 2.2 Hi-Res 无损音乐馆与动态 LRC 歌词同步 (Hi-Res Music Hub)
- **母带级音质支持**：支持 24-bit/192kHz FLAC、DSD128 (Direct Stream)、WAV、AAC、MP3 等高清音频格式播放。
- **实时同步高亮滚动歌词 (LRC Lyrics Sync)**：
  - 内置时间轴歌词解析器，毫秒级追踪音频进度，当前歌词行智能高亮放大并平滑居中滚动。
  - 支持点击任意歌词行即时跳转（Click-to-Seek）到对应音频时间点。
  - 支持导入本地 `.lrc` 歌词文件，或在可视化编辑器中实时编辑歌词时间轴并保存。
- **专辑封面更新与在线元数据刮削**：
  - 点击专辑封面即可选择在线备用封面或上传本地图片更新。
  - 支持调用 MusicBrainz 音乐库一键刮削歌曲信息并自动补全歌词。
- **本地音乐文件导入**：支持直接从本地硬盘选择音频文件导入至音乐库，并自动持久化存储。

### 2.3 真实 GPU 硬件解码管线探测与转码控制台 (HW Transcoder & GPU Diagnostics)
- **物理 GPU 硬件真实检测**：
  - 通过 WebGL 底层硬件查询接口 (`WEBGL_debug_renderer_info`) 及 WebGPU 适配器，直接获取宿主机**实际物理显卡型号**（如 NVIDIA GeForce RTX 系列、Apple Silicon M 系列 GPU、Intel Iris Xe、AMD Radeon）。
- **W3C MediaCapabilities 硬件解码认证 (`powerEfficient: true`)**：
  - 依照 W3C 国际标准执行 4K 60fps AV1、4K 60fps HEVC/H.265 (Main10)、4K 60fps H.264、8K 60fps VP9 硬件解码测试。
  - 当 `powerEfficient: true` 时，权威证明当前运行环境**实际调用了操作系统与显卡的专用硬件 ASIC 视频解码单元**（NVDEC / Intel QSV / Apple VideoToolbox / VA-API），而非 CPU 软件模拟解码。
- **实时 WebGL 着色器渲染测试**：内置 GPU Shader 画布，以 144+ FPS 实时渲染并测量逐帧渲染耗时（<1ms）。
- **原生桌面端 FFmpeg CLI 桥接说明**：在桌面二进制环境下，NovaStream 后台直调 `-hwaccel cuda` / `-hwaccel qsv` / `-hwaccel videotoolbox` / `-hwaccel vaapi`，实现 100% 显卡硬件解码与流转码。
- **硬件级 HDR 动态色调映射 (Tone Mapping)**：
  - 算法支持：`Hable Filmic`、`Reinhard`、`Mobius`，BT.2020 广色域自动精准映射至 BT.709。
  - 零磁盘磨损缓冲：支持通过内存盘 `/dev/shm` 进行分片预转码。

### 2.4 沉浸式影院播放器与硬件遥测 (Cinema Player & HUD)
- **多轨流媒体切换**：支持原始直接直通（Direct Play，0% GPU 负载）、4K HEVC 28Mbps、1080p AV1 12Mbps 等多级档位。
- **多音轨与多字幕**：无损切换杜比全景声、DTS-HD MA 5.1 与国语配音；支持 ASS 特效双语字幕及 SRT 字幕，并提供 ±200ms 时间轴微调。
- **硬件遥测仪表板 (HUD)**：按 <kbd>H</kbd> 键随时呼出浮动监测面板，实时查看转码速度 (FPS)、GPU 编解码负载、显存占用、核心温度与缓冲深度。

### 2.5 跨平台 GUI 窗体与零药丸设计语言
- **桌面标题栏随心切换**：
  - **macOS**：红黄绿交通灯、毛玻璃质感、系统代理标题。
  - **Windows 11**：Fluent 亚克力边框、窗口最小化/最大化/关闭按钮。
  - **Linux**：GTK4 / Adwaita 沉浸式无边框模式。
- **高级排版规范**：元数据一律采用点号 `·` 或斜杠 `/` 进行非药丸化排版，阅读体验纯粹舒适。

### 2.6 本地磁盘挂载、持久化与主流媒体格式支持
- **双模式本地磁盘挂载**：
  - **模式 1：本地电脑真实文件夹选择 (Native File System / HTML5 Directory Picker)**：直接调用系统文件对话框，选择电脑硬盘中任意视频目录（如 `D:\Movies` 或 `/Users/...`），自动提取视频文件生成可播放的 Blob 流，自动刮削元数据并一键入库。
  - **模式 2：指定物理路径挂载与深度索引**：输入 Windows NTFS 盘符、macOS APFS 卷或 Linux 挂载点，系统自动深度扫描并索引对应分类影片，计算总容量并绑定对应 NFO。
- **全局持久化存储 (`localStorage`)**：所有新挂载的目录、新增电影记录、刮削结果与播放进度均自动持久化存入本机，页面刷新（F5）或重启后依然完好保留。
- **多语言即时本地化**：完整支持 **简体中文 (zh-CN)**、**繁體中文 (zh-TW)**、**English (en)** 与 **日本語 (ja)**。
- **兼容主流影音格式**：
  - 视频容器：`MKV (Matroska)`, `MP4`, `ISO (BD-ISO 蓝光原盘)`, `TS`, `M4V`, `WebM`
  - 音频格式：`Dolby Atmos TrueHD 7.1`, `DTS-HD MA`, `FLAC 无损`, `EAC3`, `AAC`
  - 字幕标准：`ASS/SSA`, `SRT`, `VTT`, `PGS/SUP`
  - 元数据：`Kodi/Emby XML NFO`

## 4. 快捷键指南

在进入影院视频播放器后，支持以下全键盘快捷操作：

| 快捷键 | 功能描述 |
| :---: | :--- |
| <kbd>Space</kbd> | 播放 / 暂停切换 |
| <kbd>←</kbd> | 后退 10 秒 |
| <kbd>→</kbd> | 快进 10 秒 |
| <kbd>↑</kbd> | 音量增加 5% |
| <kbd>↓</kbd> | 音量减少 5% |
| <kbd>M</kbd> | 静音 / 恢复音量切换 |
| <kbd>F</kbd> | 全屏模式进入 / 退出 |
| <kbd>H</kbd> | 开启 / 关闭硬件转码遥测 HUD 浮窗 |
| <kbd>Esc</kbd> | 退出播放器返回影音库 |

## 5. 运行与构建说明

### 本地开发
```bash
# 安装依赖
npm install

# 若在特定 npm 版本遇到依赖树冲突，可使用：
# npm install --legacy-peer-deps

# 启动开发服务器 (默认端口 3000)
npm run dev
```

### 类型检查与生产构建
```bash
# 静态类型检查
npm run lint

# 生产环境构建打包
npm run build
```
